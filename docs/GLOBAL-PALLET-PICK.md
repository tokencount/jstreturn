# Global pallet location picking — Cc1319

Pallet previews and print are read-only projections. One repeatable-read snapshot loads every active ticket and imported stock/location rows. The existing matcher pallet projection/ranking is retained; persisted READY tickets alone receive deterministic positive-location assignments. All Main Bin+Pack imported locations are usable; E is not a warehouse rule. A child inventory row takes precedence over legacy snapshot fallback; snapshot-only positive stock requires a nonblank location.

Capacity is consumed globally per SKU/location, never restarted for each requested pallet. Duplicate part rows share one SKU demand and slice the per-item assignment. Each original part carries pick_locations and pick_missing; frontend screen and print sum only selected items assignments, never reallocate from raw stock or fall back locally. Short/inconsistent assignments disable picking print. The print preflight refetch checks a signature containing selected-pallet items and assignments. Product-location editing remains separate from component inventory locations.

No stock, ticket fields, statuses or reservation records are changed by either pallet GET. Existing importer/edit matcher remains the status writer. These allocations are deterministic projections for one data version, not physical stock movements, persistent picking claims, or a guarantee against printing the same ticket twice. Changed source or tickets may produce a different plan; the print signature requires review when changed. Automatic source scope is enforced by the existing hash-bound Main Bin+Pack importer; arbitrary manual-upload provenance is not inferred from location text.

All screen/print views use the same getter and per-item server assignments. Purchase exports retain their existing globally reserved SKU shortages/date logic, and Shopee is unchanged. Regression: tests/test_global_location_picking.py, tests/test_pallet_pick.py, tests/test_global_pallet_ui.cjs (optionally pass a sanitized full set of pallet responses to verify all quantities and global location capacities).
